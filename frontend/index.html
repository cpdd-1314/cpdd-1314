第一次使用？三步创建令牌
  1. 打开 GitHub 令牌创建页，Note 随便填（如 cpdd-site）
  2. Expiration 选「No expiration」，勾选唯一权限 public_repo
  3. 点底部绿色「Generate token」，复制生成的 ghp_ 开头令牌，粘贴到上方输入框

令牌只保存在你自己的浏览器里，用于把资料写进你的仓库；随时可在 GitHub 设置里删除，删除后访客浏览不受影响。
